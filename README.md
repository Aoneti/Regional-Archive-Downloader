YARchive Downloader

Расширение для Google Chrome, позволяющее скачивать оцифрованные документы из \*\*Архива Ярославской области\*\*. Работает со справочно-информационным фондом и автоматически скачивает страницы документа в виде изображений.

✨ Возможности

\- 📄 Скачивание \*\*текущей страницы\*\* документа

\- 📚 Скачивание \*\*всего документа целиком\*\*

\- 🗂 Автоматическое создание папок по каждому `unit`

\- ⏸ Пауза и ▶ продолжение загрузки

\- ⛔ Остановка процесса в любой момент

\- 🌗 Светлая и тёмная тема интерфейса

Идея взята у yandex-archive-downloader
