# YARchive Downloader

**Расширение для Google Chrome**, которое позволяет **автоматически скачивать оцифрованные документы** из Архива Ярославской области (работает со справочно-информационным фондом **https://af.yar-archives.ru/archive27/funds/1**).

Страницы сохраняются в формате `.jpg`.

---

## Возможности

- Скачивание **всего документа** одним нажатием
- Скачивание **только текущей страницы**
- **Автоматический поиск** количества страниц
- **Пауза / Возобновление / Остановка** в любой момент
- Создание удобных папок `Название_документа_unit_12345`
- Настраиваемая задержка между скачиваниями
- Темная и светлая тема интерфейса
- Сохранение всех настроек в браузере

---

Идея и часть логики взята из проекта [yandex-archive-downloader](https://github.com/search?q=yandex-archive-downloader).
