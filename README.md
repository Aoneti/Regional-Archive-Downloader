# YARchive Downloader

Расширение для Chrome, позволяющее скачивать оцифрованные документы из Архива Ярославской области.

---

## О расширении

**YARchive Downloader** автоматизирует загрузку страниц документов из справочно-информационного фонда [Архива Ярославской области](https://af.yar-archives.ru/archive27/funds/1). Расширение последовательно скачивает страницы просматриваемого документа в виде изображений — без необходимости сохранять каждую страницу вручную.

Идея вдохновлена проектом [yandex-archive-downloader](https://github.com/).

---

## Возможности

- Автоматическая загрузка страниц в виде изображений
- Скачивание всех страниц документа одним нажатием
- Настраиваемые параметры загрузки в меню настроек
- Работа непосредственно на сайте архива без сторонних сервисов

---

## Установка

Расширение устанавливается вручную в режиме разработчика.

1. Скачайте репозиторий и распакуйте архив.
2. Откройте Chrome и введите в строке поиска:
   ```
   chrome://extensions/
   ```
3. Включите **Режим разработчика**.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с репозиторием.
5. Расширение появится в панели инструментов браузера.

---

## Использование

1. Перейдите на страницу документа в [справочно-информационном фонде](https://af.yar-archives.ru/archive27/funds/1).
2. Откройте документ для просмотра.
3. Нажмите на иконку расширения.
4. В появившемся меню нажмите кнопку скачивания.
5. Страницы документа будут автоматически загружены в папку загрузок.

---

## Ограничения

- Расширение работает **только** с сайтом `af.yar-archives.ru`.
- Для загрузки требуется открытая страница просмотра документа.
- Скорость загрузки зависит от скорости интернет-соединения и отклика сервера архива. **Внимание**: серверы архива могут не выдержать большой нагрузки, поэтому не стоит злоупотреблять массовой загрузкой. Старайтесь отправлять файлы с небольшой задержкой между загрузками.

## Планы
