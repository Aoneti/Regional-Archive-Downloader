## 📖 Описание

**Regional Archive Downloader** — расширение для браузера, которое позволяет скачивать страницы архивных документов в виде изображений или собирать их в единый PDF-файл.

> ⚠️ **Важно:** Расширение находится в активной разработке и не проверено на большинстве поддерживаемых архивов. Часть функций может работать иначе, чем ожидается. **Если что-то не работает или работает неправильно — пожалуйста, напишите об этом:**
> 👉 **https://t.me/orsegen**
> Ваша обратная связь напрямую определяет, что будет исправлено и добавлено.

## ✨ Возможности

### Основные функции
- **Скачать документ** — автоматическое скачивание всех страниц одним нажатием
- **Скачать PDF** — сборка всех страниц в единый PDF-файл (до 500 страниц за раз)
- **Скачать текущую страницу** — быстрое сохранение открытой страницы
- **Диапазон страниц** — гибкий слайдер для выбора нужных страниц
- **Пауза и возобновление** — контроль процесса загрузки в любой момент

### Дополнительные возможности
- 📁 Создание отдельных папок для каждого документа
- 📊 Экспорт метаданных документа (CSV, JSON, BibTeX)
- 📝 Заметки к документам
- 📜 История загрузок с быстрым переходом к документу
- 🌓 Тёмная / светлая / системная тема интерфейса
- ⚡ Адаптивная скорость загрузки (автоматически снижается при ошибках сервера)

## 📦 Установка

1. **Скачайте ZIP-архив и распакуйте его**

2. **Активируйте режим разработчика в Chrome**
   - Откройте `chrome://extensions/`
   - Включите переключатель **«Режим разработчика»**

3. **Загрузите расширение:**
   - Нажмите **«Загрузить распакованное расширение»**
   - Выберите папку с файлами расширения

4. **Готово!** Иконка расширения появится в панели инструментов браузера

При выходе новых версий:
1. Удалите старую версию через `chrome://extensions/`
2. Повторите шаги установки с новой версией

## ⚙️ Технические детали

### Требования
- **Браузер**: Google Chrome 88+ или совместимый Chromium-браузер
- **Разрешения**:
  - `downloads` — управление загрузками
  - `activeTab` — доступ к активной вкладке архива
  - `storage` — хранение настроек и заметок

### Архитектура
```
├── manifest.json          # Конфигурация расширения
├── background.js          # Service Worker для фоновых операций
├── content-script.js      # Скрипт для взаимодействия со страницей архива
├── popup.html / popup.js  # Интерфейс быстрого доступа
├── options.html           # Страница настроек
├── options.js             # Логика настроек
├── options-archives.js    # Список поддерживаемых архивов
└── icons/                 # Иконки расширения
```

## ⚠️ Ограничения и рекомендации

### Ограничения
- Работает только с указанными на странице настроек архивами
- Требуется открытая страница просмотра документа
- PDF ограничен 500 страницами за один запуск (используйте диапазон слайдера для больших документов)
- Некоторые архивы могут ограничивать скорость ответов

### Рекомендации по использованию
> **Важно**: Серверы архивов имеют ограниченную производительность. Для стабильной работы:
> - Используйте задержку не менее **250 мс** между запросами
> - Включите **адаптивную скорость** для автоматической регулировки
> - Избегайте массовых параллельных загрузок (>4 потоков)
> - При получении ошибок 429/503 увеличение задержки происходит автоматически

### Особенности отдельных архивов
- **Кострома, Приморье**: перед скачиванием обязательно прокрутите ленту миниатюр до конца — расширение скачивает только те страницы, которые были загружены в ленту
- **ЭЛАР-архивы**: расширение автоматически определяет сетку тайлов; первый запуск может занять несколько секунд на зондирование
